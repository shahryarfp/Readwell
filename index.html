Your Drive library

Google Drive setup is required once before connecting.

Save a named copy to your Readwell folder, then connect with the same Google account on your phone. Texts are stored in Drive, never in GitHub. Keep the folder private.

One-time Google Drive setup
  1. Publish this file as index.html using GitHub → repository Settings → Pages → Deploy from a branch → main / root. Open the resulting HTTPS website.
  2. In Google Cloud Console, create or select a project and enable Google Drive API.
  3. In Google Auth Platform, configure Branding and Audience (External). While in Testing, add your own Google email under Test users. In Data Access, add https://www.googleapis.com/auth/drive.file.
  4. Create an OAuth client of type Web application. Add this exact Authorized JavaScript origin: . Use only the origin, with no repository path. This popup flow needs no redirect URI.
  5. Copy the client ID ending in .apps.googleusercontent.com into the google-client-id meta tag at the top of this file and publish the updated file. This ID is public; never add a client secret. Both devices must use the same client ID.

Then click Connect Google Drive and allow access. The app creates its own Readwell folder; you do not need to create or share a folder. Open the same website and sign in on your phone. Use Refresh to fetch recent saves.

If Google reports an origin mismatch, check the exact origin above. If access is blocked in Testing, check the test-user email. Allow sign-in popups and use your normal browser rather than an embedded browser. New Google settings can take time to apply.

Connections expire periodically; reconnect when prompted. Reloading the page also requires reconnecting. Your saved texts remain in Drive. Unsaved edits are not backed up. Online voices may send text to their speech provider; phone voices and background playback depend on the browser.
